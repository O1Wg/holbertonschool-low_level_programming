# Holberton School – Low-Level Programming

My C projects from the **Holberton School Software Engineering Intensive Program (SEIP)** at **Tuwaiq Academy**.

This repo tracks my progress in low-level programming, starting from my very first `Hello, World` and working up to pointers, arrays, and strings. Each folder is a separate project with its own tasks.

## Projects

| Project | What it covers |
|---|---|
| [hello_world](./hello_world) | First C programs, the compilation steps (preprocessor, compiler, assembler, linker), `puts`, `printf`, and data type sizes |
| [variables_if_else_while](./variables_if_else_while) | Variables, `if`/`else` conditions, `while` and `for` loops, and printing with `putchar` |
| [functions_nested_loops](./functions_nested_loops) | Writing functions, header files, prototypes, and nested loops |
| [more_functions_nested_loops](./more_functions_nested_loops) | More practice with functions and nested loops: printing patterns and number problems |
| [intro_debugging](./intro_debugging) | Reading errors, tracing code, and finding and fixing bugs |
| [pointers_arrays_strings](./pointers_arrays_strings) | Pointers, arrays, strings, and basic string manipulation |
| [simple-calculator](./simple-calculator) | A simple calculator program written in C |
| [benchmarking](./benchmarking) | Measuring and comparing the performance of code |

## Requirements

- Compiled with `gcc` using the flags `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Code follows the [Betty](https://github.com/holbertonschool/Betty) style guide
- All files end with a new line

## How to compile and run

```bash
git clone https://github.com/O1Wg/holbertonschool-low_level_programming.git
cd holbertonschool-low_level_programming/<project_folder>
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 <file>.c -o <program>
./<program>
```

Some tasks need a `main.c` file to test them, so compile it together with the task file:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 main.c <task_file>.c -o <program>
```
