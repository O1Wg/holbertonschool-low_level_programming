# more_functions_nested_loops

Exercises from the Holberton School low-level programming curriculum,
practicing functions and nested loops in C.

## Requirements

- Compiled with `gcc -Wall -pedantic -Werror -Wextra -std=gnu89`
- Code follows the Betty style (`betty-style` and `betty-doc`)
- All function prototypes are in `main.h`

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes |
| `_putchar.c` | Writes a character to stdout |
| `0-isupper.c` | Checks for an uppercase character |
