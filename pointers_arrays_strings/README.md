# C - Pointers, Arrays, and strings

## Description

This project is about how data is stored and transformed in the program.

- A pointer is a variable that stores the address of another variable.
- An array is a collection of items of the same type, stored next to each other in memory.
- A string is an array of characters that ends with `'\0'`.
